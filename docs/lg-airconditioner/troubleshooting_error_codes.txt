IMPORTANT SCOPE AND SAFETY NOTICE
This guide expands the error-code notes supplied for this document. Error-code meanings and diagnostic procedures can vary by LG product family, region, controller, indoor/outdoor combination and model revision. The codes and descriptions below are based on the supplied reference list and are not confirmed as universally applicable to every LG inverter split AC, including the UW-Q18WUZA.

Before using a code to diagnose or replace a component, verify it against the official service manual for the exact model and product revision. Do not assume a code has the same meaning across all LG models.

Customer-safe actions are limited to external visual checks and the reset procedure explicitly permitted by the product's user manual. Do not instruct customers to open electrical covers, probe terminals, measure resistance or voltage, manipulate fan blades, replace fuses, handle refrigerant, or replace PCBs. Electrical, refrigerant, pressure and internal component tests are for qualified technicians using the correct service manual and equipment.

GENERAL CUSTOMER GUIDANCE
1. Record the exact error code as displayed, including any leading zero.
2. If there is smoke, a burning smell, sparking, repeated breaker trips, water near electrical equipment, or a damaged cable, stop using the unit and isolate power only if it is safe to do so. Contact qualified service.
3. For codes that permit a reset, follow the exact product's user manual. Do not repeatedly cycle the breaker to suppress a recurring fault.
4. Keep the outdoor unit's air inlet and outlet clear of loose debris, but do not remove covers or insert tools through the grille.
5. If a code returns after an allowed reset, arrange service and provide the code and symptom history.
6. The diagnostic suggestions in this document are not a substitute for the official code-specific flowchart.

CH 01 — INDOOR AIR INLET THERMISTOR ERROR
Category: Sensor
Severity in supplied reference: Medium
Description in supplied reference: Indoor air inlet thermistor open/short.

What it may indicate
The control system may be detecting an abnormal signal from the indoor room-air temperature sensor or its circuit. A code alone does not prove the sensor itself has failed.

Customer actions
1. Record the code and any unusual behavior.
2. If the product manual permits a reset, switch the unit off and follow the manual's reset procedure.
3. Do not open the indoor unit or pull on sensor wiring.
4. If the code returns, book service.

Technician checks
1. Confirm the exact code definition for the model.
2. Isolate power and follow the service manual's electrical-safety procedure.
3. Inspect the indoor air sensor, harness and connector for damage, moisture or a loose connection.
4. The supplied reference suggests checking resistance at 25°C in a 5 kΩ–10 kΩ range and checking connector CN-TH1. These details are unverified; use the model-specific sensor resistance table and connector designation.
5. Compare measured resistance with the manufacturer's temperature/resistance chart rather than a broad range alone.
6. Check the relevant PCB input only using the official procedure.

Possible parts listed in supplied reference
Indoor air sensor; main PCB.

Do not replace the PCB or sensor based only on the code. Confirm the sensor, wiring and specified test results first.

CH 03 — INDOOR/OUTDOOR COMMUNICATION OR WIRING ERROR
Category: Communication
Severity in supplied reference: High
Description in supplied reference: Wiring error or indoor/outdoor communication failure.

Customer actions
1. Note whether the outdoor unit appears to start, without touching it or listening close to moving parts.
2. Check only for obvious external obstruction or visible cable damage from a safe location.
3. If the user manual permits, perform one reset using the specified procedure.
4. If the error returns, stop repeated resets and contact service.

Technician checks
1. Verify the code meaning and communication topology for the exact model.
2. Isolate power before inspecting terminal blocks or interconnecting cables.
3. Compare terminal-to-terminal wiring with the official diagram; do not rely on wire color alone.
4. Inspect for loose terminals, damaged insulation, corrosion, moisture or an incorrect connection.
5. Test continuity and signal behavior only as specified by the official service procedure.
6. Test indoor/outdoor PCB operation only after wiring and supply checks have been completed.

The supplied reference mentions F1/F2 or L1/L2. These labels are not interchangeable across all models. Use only the terminals identified by the exact wiring diagram.

Possible parts listed in supplied reference
Communication wire; indoor PCB; outdoor PCB.

Safety
Electrical diagnostic work is technician-only. Do not probe live or unidentified terminals.

CH 04 — DRAIN PUMP ERROR OR FLOAT SWITCH OPEN
Category: Drainage
Severity in supplied reference: Medium
Description in supplied reference: Drain pump error or float switch open.

Applicability note
A drain pump and float switch may be present on certain indoor-unit designs or installations. Confirm that the specific indoor unit has these components; do not assume all wall-mounted split units use a drain pump.

Customer actions
1. Check for visible water leakage.
2. If water is leaking indoors, turn the AC off. Keep water away from sockets and electrical equipment.
3. If the drain hose is visible and safely accessible, check for an obvious kink, crushing or submerged outlet.
4. Do not dismantle the unit or pour chemicals into the drain.
5. Book service if the code remains or leakage occurs.

Technician checks
1. Confirm the installed drain arrangement and code definition.
2. Inspect the drain pan and accessible hose route.
3. Check for a blockage or incorrect hose slope.
4. Test the drain pump and float switch using the official procedure.
5. Inspect connectors and control inputs for damage or moisture.
6. Perform a controlled drainage test and check for leaks after repair.

Possible parts listed in supplied reference
Drain pump; float switch.

CH 05 — INDOOR/OUTDOOR COMMUNICATION ERROR
Category: Communication
Severity in supplied reference: High
Description in supplied reference: Communication error between indoor and outdoor units.

Customer actions
1. Record the code and when it appears.
2. Check for obvious external cable damage only from a safe location; do not touch exposed or damaged wiring.
3. If the product manual allows, perform one reset according to its instructions. The supplied reference mentions turning the MCB off for five minutes, but this interval must be verified against the exact product's instructions.
4. If the code returns, stop resetting and arrange qualified service.

Technician checks
1. Confirm the CH 05 definition for the exact model; code meanings vary across product families.
2. Isolate power and inspect interconnecting wiring and terminal connections.
3. Confirm terminal assignments from the official wiring diagram. Do not assume L1/L2 are communication terminals.
4. The supplied reference states that DC voltage between L1 and L2 should fluctuate between 0 V and 24 V. This is unverified and must not be used as a universal pass/fail range. Test only the manufacturer-designated terminals, using the specified meter and operating conditions.
5. Verify supply and wiring before considering a PCB fault.
6. Follow the official flowchart to distinguish a cable, connector, supply or PCB problem.

Possible parts listed in supplied reference
Communication wire; indoor main PCB; outdoor main PCB.

Do not replace the indoor PCB first as a blanket rule. Replace a PCB only when the official diagnostic process supports that conclusion.

CH 29 — COMPRESSOR ROTATION / PHASE ERROR
Category: Compressor
Severity in supplied reference: High
Description in supplied reference: Compressor rotation or phase-related error.

Applicability and correction
The supplied reference suggests swapping two input phases for three-phase models and checking wiring/capacitor for single-phase models. Do NOT apply this as a generic instruction. Many inverter split AC compressors are driven by an inverter and do not use a conventional field correction by swapping supply phases. The correct procedure depends on the exact product and system design.

Customer actions
1. Turn the unit off.
2. If electrical work was recently performed, tell the installer or service technician.
3. Do not alter wiring or swap conductors yourself.
4. Arrange qualified service if the error persists.

Technician checks
1. Verify the exact code definition and power/compressor architecture.
2. Inspect wiring against the official diagram with power isolated.
3. Confirm connector positions and phase/rotation diagnostic steps as prescribed by LG.
4. Check inverter output and compressor feedback only using the approved procedure.
5. Do not swap wires or bypass a phase/rotation protection device without explicit model-specific instructions.

Possible parts/actions listed in supplied reference
Wiring correction; phase-reversal protection component where fitted.

CROSS-CODE SAFETY RULES

1. Electrical codes (including CH 03, CH 05, CH 21, CH 22, CH 23, CH 27 and CH 65 in the supplied list) must be handled by qualified personnel.
2. Compressor codes (including CH 26 and CH 67) should not trigger repeated restart attempts.
3. Drainage codes (CH 04 and CH 10) require attention to indoor water leakage and nearby electrical hazards.
4. Sensor codes do not automatically prove a sensor has failed; wiring, connectors, placement, temperature and PCB input can also be involved.
5. Pressure and temperature protection codes must not be bypassed. Do not add or remove refrigerant without the correct diagnosis.
6. Do not replace a PCB, compressor, motor or sensor solely because a code appears. Follow the official diagnostic sequence.
7. Do not assume a capacitor, pressure switch, float switch, drain pump or particular sensor exists in every unit. Confirm the actual model design.
8. Do not use generic resistance or voltage values as model-specific pass/fail criteria unless verified against official documentation.
9. Do not treat a code list from a different LG product family as authoritative for the UW-Q18WUZA.
10. If the displayed code does not match the code definitions in the exact model's manual, stop and verify the product identity and documentation.
